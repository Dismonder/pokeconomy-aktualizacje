# Pokeconomy – jak zaktualizować grę

Serwer ma nową wersję: **Pixelmon 9.4.2** i **NeoForge 21.1.248**. Bez tej aktualizacji serwer Cię nie wpuści.

## Aktualizacja z wcześniejszego wydania
To wydanie przechodzi na NeoForge 21.1.248 i Pixelmona 9.4.2. Aktualizator nie zmienia loadera i nie dostarcza Pixelmona, więc przed pierwszym startem zrób to ręcznie:

1. Zamknij grę i launcher.
2. Zmień wersję NeoForge swojej instancji na **21.1.248**: w Prism Launcher *Edytuj instancję → Wersje → NeoForge*
   (w oficjalnym launcherze uruchom [instalator NeoForge 21.1.248](https://maven.neoforged.net/releases/net/neoforged/neoforge/21.1.248/neoforge-21.1.248-installer.jar) → *Install client*).
3. Pobierz [**Pixelmon 9.4.2** z Modrinth](https://modrinth.com/mod/pixelmon/version/l63weWf0) i w folderze `mods` podmień nim stary plik Pixelmon 9.3.16 (usuń starą wersję).
4. Uruchom grę jak zwykle – aktualizator dociągnie resztę modów.
